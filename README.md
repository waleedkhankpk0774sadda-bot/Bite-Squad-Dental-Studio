# Bite Squad Dental Studio

Premium responsive static website built with HTML, CSS and JavaScript.

## Included
- index.html
- style.css
- script.js
- assets/images/ with the supplied logo and local dental photography used throughout the site

## Run
Open `index.html` directly in a modern browser. No build step is required.

The appointment form is front-end only; connect it to a real backend/email service for production. Replace placeholder contact details in `index.html`.
